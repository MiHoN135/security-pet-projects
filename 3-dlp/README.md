# DLP: предотвращение утечек

Проверяет каждое сообщение по правилам из `rules.json`:
- `block` — сообщение не доставляется, пользователь получает причину;
- `warn` — сообщение доставляется, в лог пишется предупреждение.

Файл `rules.json` перечитывается каждые 5 секунд, перезапуск не нужен. Битый файл не роняет проверку: остаются прежние правила.

```bash
python3 test_dlp.py
```
