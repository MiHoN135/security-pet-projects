# Pet-проекты по информационной безопасности

Пять пет-проектов, каждый по одной лабораторной-презентации курса, каждый по одной лабораторной-презентации курса «Современные методы и средства программирования задач информационной безопасности».

| Папка | Тема | Стек |
|---|---|---|
| [1-grpc-messenger](1-grpc-messenger/) | Консольный мессенджер с аутентификацией | Python, gRPC, SQLite |
| [2-totp-2fa](2-totp-2fa/) | Двухфакторная аутентификация (TOTP, RFC 6238) | Python (stdlib) |
| [3-dlp](3-dlp/) | DLP: поиск утечек карт, паспортов и телефонов | Python (stdlib) |
| [4-file-signature](4-file-signature/) | Проверка целостности: SHA-256 и подпись RSA-PSS | Python, cryptography |
| [5-steganography](5-steganography/) | Скрытие текста в PNG (LSB) | Python, Pillow, numpy |

Каждую папку можно запускать отдельно. Тесты запускаются командой `python3 test_*.py` внутри папки.
