# Система контроля и аудита доступа к файлам

Курсовая работа: консольная система, где доступ к файлам выдаётся пользователям по правам (read, write, delete), каждая операция попадает в журнал аудита.

## Возможности
- Регистрация и вход; первый зарегистрированный пользователь становится администратором
- Вход выдаёт JWT-токен (PyJWT, HS256, срок 1 час)
- Права на файлы: администратор выдаёт `read`, `write`, `delete` конкретным пользователям
- Все успешные и неуспешные операции записываются в таблицу `audit` (SQLite)
- Путь к файлу нормализуется (защита от `../`)

## Структура
- `main.py` — запуск консоли
- `auth/` — пароли и JWT
- `storage/` — SQLite: пользователи, права, аудит
- `fs/secure_file.py` — операции с файлом с проверкой прав
- `cli/` — команды, обработчики, REPL
- `audit/` — запись в журнал
- `test.py` — тесты

## Запуск
```bash
pip install -r requirements.txt
python3 main.py            # интерактивная консоль, введите help
python3 test.py            # тесты
```

## Ограничения (известные)
- Пароли хешируются SHA-256 без соли. Для продакшена нужен bcrypt или argon2.
- Ключ JWT берётся из переменной окружения `JWT_SECRET`, если она не задана, используется ключ для разработки.
